متجر العطّار - Flask

تشغيل محلي على Windows:
1) ثبّت Python 3.11 أو 3.12.
2) افتح PowerShell داخل مجلد المشروع.
3) نفّذ: py -m venv venv
4) نفّذ: .\venv\Scripts\Activate.ps1
5) نفّذ: pip install -r requirements.txt
6) نفّذ: python app.py
7) افتح: http://127.0.0.1:5000

النشر على Render:
- ارفع جميع محتويات هذا المجلد إلى جذر مستودع GitHub.
- اختر Web Service.
- Build Command: pip install -r requirements.txt
- Start Command: gunicorn app:app
- أضف Environment Variables:
  SECRET_KEY = قيمة طويلة عشوائية
  WHATSAPP_NUMBER = 962781611698
  ADMIN_PASSWORD = كلمة مرور قوية
- قاعدة SQLite المحلية قد لا تكون دائمة على استضافات لا توفر قرصاً دائماً؛ الخصومات قد تعود للوضع الافتراضي بعد إعادة تشغيل الخدمة على الخطة المجانية.

ملاحظات:
- العطور 120 اسماً بالضبط، وخيارات العبوة 1 أو 3 أو 5 دنانير.
- الزيوت المدرجة لا تتضمن زيت الزيتون وسعر كل عبوة 1 دينار.
- كل بذور الزراعة بسعر 2 دينار.
- صور البطاقات الحالية رسومات زخرفية وليست صوراً فوتوغرافية حقيقية.
- صفحة /admin مخصصة لتطبيق خصومات على الأقسام، ولا توفر حالياً إضافة منتجات جديدة أو رفع صور.
